# "1. Гілка (branch) в Git - це незалежна лінія розробки, яка дозволяє ізольовано працювати над новими функціями."
# "2. Вона дозволяє вносити зміни, не впливаючи на основну версію коду в гілці main."
# "3. Злиття (merge) об'єднує зміни з різних гілок через створення спеціального коміту злиття."
# "4. При використанні merge зберігається повна розгалужена історія розробки обох гілок."
# "5. Перебазування (rebase) бере коміти поточної гілки і переносить їх на верхівку іншої цільової гілки."
# "6. Відмінність полягає в тому, що rebase переписує історію, роблячи її лінійною, змінюючи при цьому хеші комітів."md
